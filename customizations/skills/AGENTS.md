# Skill Customizations

## Purpose

Own reusable operational guidance, references, and optional skill-scoped MCP setup.

## Ownership

- Extension resources or configured skill roots own discoverable skill files.
- This directory owns policy notes only.

## Local Contracts

- Give each skill one capability boundary and explicit trigger description.
- Keep references local and portable; do not rely on machine-only paths.
- Treat skill content as guidance, not a privilege escalation mechanism.

## Work Guidance

- Load only task-relevant references.
- Use skill metadata for narrowly scoped MCP requirements where supported.

## Verification

- Verify skill discovery in a live OMO session and inspect its declared resources.

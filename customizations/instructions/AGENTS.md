# Rules and Prompt Customizations

## Purpose

Own durable agent rules, prompt overlays, and scoped instruction patterns.

## Ownership

- `~/.omo/rules/` owns global user rules.
- Project `AGENTS.md` and `.omo/omo.jsonc` own repository scope and prompt configuration.

## Local Contracts

- Use `prompt_append` or global rules for additive behavior.
- Use full `prompt` replacement only when loss of host presets is intentional.
- State scope, precedence, and enforceable companion controls for every policy.

## Work Guidance

- Keep one policy per file and avoid credential examples.
- Test a noninteractive prompt echo after changing prompt assembly behavior.

## Verification

- Confirm target instruction loads while native OMO system behavior remains present.

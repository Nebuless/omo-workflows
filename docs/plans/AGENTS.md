# Unified Plan Artifacts

## Purpose

Own Compound Engineering requirements and implementation plan artifacts.

## Ownership

- Each dated plan file owns one Product Contract and any implementation planning added by `ce-plan`.

## Local Contracts

- Keep `artifact_contract: ce-unified-plan/v1` and the original `product_contract_source` stable. Use `ce-brainstorm` for brainstormed contracts and `ce-plan-bootstrap` for plans created directly from a concrete request.
- Use the canonical dated filename format and repo-relative references.
- Do not add implementation sections until `ce-plan` enriches the artifact.

## Work Guidance

- Preserve confirmed product decisions and explicit scope boundaries.
- Update a matching artifact in place when resuming its topic.

## Verification

- Run the CE Ready for Planning Check for requirements artifacts and the `ce-plan` coverage/consistency review for implementation plans before handoff.
